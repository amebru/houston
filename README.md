# Houston

[Houston](https://en.wikipedia.org/wiki/Christopher_C._Kraft_Jr._Mission_Control_Center) is an LLM-agent for intelligently delivering calendar notifications using [Restack](https://www.restack.io/). This was my project for the [Restack pre-YC S25 Hackathon](https://docs.restack.io/community/hackathons/04-26-2025-berlin-pre-yc-hackathon).

This is a fork of a restack template; the original readme is in `README-restack-original.md`.
